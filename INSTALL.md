# Установка Alfa 156

Alfa 156 — универсальное приложение для учета расходов автомобиля на **Android**, **Windows (Desktop)** и **Windows Mobile (КПК)**.

## Быстрый старт

### 1. Скачайте приложение

Выберите версию для вашей платформы:

- **Android**: `Alfa156-1.38.1.apk`
- **Windows Desktop**: `Alfa156-1.38.1-Desktop.exe`
- **Windows Mobile/КПК**: `Alfa156-1.38.1-KPK.exe`

[Скачать последнюю версию](https://github.com/Dolfst/alfa/tree/main/dist/download)

### 2. Установка

#### Android
1. Скачайте `Alfa156-1.38.1.apk`
2. Перейдите в файловый менеджер → найдите файл
3. Нажмите и подтвердите установку
4. Запустите приложение

#### Windows Desktop
1. Скачайте `Alfa156-1.38.1-Desktop.exe`
2. Дважды нажмите на файл для запуска (установки не требуется)
3. Приложение запустится автоматически

#### Windows Mobile/КПК
1. Скачайте `Alfa156-1.38.1-KPK.exe`
2. Используйте **Windows Mobile Device Center** или **ActiveSync** для синхронизации с КПК
3. Скопируйте файл на КПК
4. Запустите на устройстве

### 3. Первый запуск

При первом запуске приложение попросит ввести название автомобиля:

1. Введите название вашего автомобиля (например, "Toyota Corolla" или "Мой автомобиль")
2. Нажмите ОК
3. Приложение инициализирует локальную базу данных

## Использование приложение

### Локальное использование

Все данные хранятся локально на вашем устройстве:

- **Android**: `/data/data/com.alfa156.mobile/`
- **Desktop**: `%APPDATA%\Local\Alfa156\`
- **КПК**: `\My Documents\Alfa156\`

### Создание резервной копии

Используйте встроенную функцию резервного копирования:

**На всех платформах:**
- Меню → Данные → Создать копию на SD (Android/КПК)
- Меню → Данные → Создать копию в памяти КПК
- Desktop: Меню → Данные → Создать копию

Копия сохраняется в формате ZIP с полным снимком данных.

## Синхронизация между устройствами

### Wi-Fi синхронизация (Android ↔ КПК)

Синхронизируйте данные между телефоном и КПК через Wi-Fi:

1. На Android: включите точку доступа Wi-Fi
2. На КПК: подключитесь к точке доступа
3. На любом устройстве: Меню → Данные → Синхронизация по Wi-Fi
4. Введите IP-адрес другого устройства
5. Нажмите синхронизировать

### Google Sheets синхронизация (Опционально)

Для синхронизации с Google Sheets на Desktop:

1. **Создайте свой Apps Script** (инструкция ниже)
2. На Desktop: Меню → Данные → Синхронизация по Wi-Fi
3. Введите URL вашего Apps Script
4. Введите токен доступа
5. Синхронизируйте данные

Подробнее: [GOOGLE_SYNC.md](GOOGLE_SYNC.md)

## Импорт и экспорт

### Desktop версия

- **Excel**: импорт/экспорт .xlsx
- **CSV**: импорт/экспорт текстовых файлов
- **Google Sheets**: прямая синхронизация
- **ZIP**: полная резервная копия и восстановление

### Android версия

- **ZIP**: импорт/экспорт резервных копий
- **Поиск**: глобальный поиск по всем записям
- **Поделиться**: экспорт отчетов в текст или HTML

✅ Учет расходов по категориям:

## Часто задаваемые вопросы

### Данные хранятся локально?

Да, все данные хранятся только на вашем устройстве. Ничто не передается третьим лицам без вашего согласия.

### Могу ли я использовать приложение без Google?

Да, приложение полностью работает локально. Google Sheets синхронизация опциональна только для Desktop версии.

### Как перенести данные между устройствами?

Используйте Wi-Fi синхронизацию или резервные копии в формате ZIP.

### Могу ли я экспортировать данные?

Да:
- Desktop: Excel, CSV, HTML
- Android/КПК: ZIP, текст
- Все платформы: резервная копия ZIP с полным снимком

## Решение проблем

### Приложение не запускается

**На Desktop:**
- Убедитесь, что установлена .NET Framework 4.8 или выше
- Запустите как администратор

**На Android:**
- Убедитесь, что Android 6.0 или выше
- Дайте необходимые разрешения при запросе

**На КПК:**
- Убедитесь, что установлена .NET Compact Framework 3.5
- Перезагрузите устройство

### Данные не синхронизируются

- Проверьте подключение Wi-Fi
- Убедитесь, что оба устройства в одной сети
- На Desktop: проверьте правильность URL Google Apps Script

### Как восстановить данные из резервной копии?

Меню → Данные → Восстановить копию → выберите ZIP файл
