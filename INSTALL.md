# Установка KiloLedger

[English](README.md#installation) · [Русский](README.ru.md#установка)

Краткая памятка. Полное описание на английском — [`README.md`](README.md), на русском — [`README.ru.md`](README.ru.md).

KiloLedger — приложение для учёта расходов автомобиля на **Android**, **Windows (Desktop)** и **Windows Mobile (КПК)**.

## Быстрый старт

### 1. Скачайте приложение

Выберите версию для вашей платформы:

- **Android**: `KiloLedger-1.39.3.apk`
- **Windows Desktop**: `KiloLedger-1.39.3-Desktop.exe`
- **Windows Mobile/КПК**: `KiloLedger-1.39.3-KPK.exe`

[Скачать последнюю версию](https://github.com/Dolfst/KiloLedger/tree/main/dist/download)

### 2. Установка

#### Android
1. Скачайте `KiloLedger-1.39.3.apk`
2. Перейдите в файловый менеджер → найдите файл
3. Нажмите и подтвердите установку
4. Запустите приложение

#### Windows Desktop
1. Скачайте `KiloLedger-1.39.3-Desktop.exe`
2. Дважды нажмите на файл для запуска (установки не требуется)
3. Приложение запустится автоматически

#### Windows Mobile/КПК
1. Скачайте `KiloLedger-1.39.3-KPK.exe`
2. Используйте **Windows Mobile Device Center** или **ActiveSync** для синхронизации с КПК
3. Скопируйте файл на КПК
4. Запустите на устройстве

### 3. Первый запуск

- **Desktop:** сначала выбор языка (он пишется в `%AppData%\KiloLedger\language.txt`), затем откройте или создайте папку данных из меню **База**.
- **Android:** при пустой базе — **Данные → Начать с нуля** и название первого автомобиля.
- **КПК:** файлы создаются в `\My Documents\KiloLedger\`.

Дальше можно добавлять заправки, ремонт и остальные записи без импорта.

## Использование приложения

### Локальное использование

Все данные хранятся локально на вашем устройстве:

- **Android**: закрытый каталог приложения, подпапка `files/KiloLedger` (`FilesDir`)
- **Desktop**: папка, которую вы открываете сами. Импорт без выбранной папки использует `Documents\KiloLedger`. Язык интерфейса — `%AppData%\KiloLedger\language.txt`. Параметры Google Sync — `%AppData%\KiloLedger\google-sync.json`
- **КПК**: `\My Documents\KiloLedger\`

### Создание резервной копии

- **Android:** копия в памяти приложения и экспорт ZIP (**Данные**).
- **КПК:** **Данные → Создать копию в памяти КПК** (`\My Documents\KiloLedger_LocalBackups\`) или **Создать копию на SD** (папка с датой на карте памяти).
- **Desktop:** экспорт ZIP из меню **Обмен**. Перед заменой базы приложение само кладёт папку `Safety_`.

Полная копия содержит файлы `.dat`, при наличии — `Receipts/` и `snapshot.json`. На КПК это папка, на Android и Desktop — ещё и ZIP.

## Синхронизация между устройствами

### Wi-Fi синхронизация (Android ↔ КПК)

Синхронизируйте данные между телефоном и КПК через Wi-Fi:

1. На Android: включите точку доступа Wi-Fi
2. На КПК: подключитесь к точке доступа
3. На любом устройстве: Меню → Данные → Синхронизация по Wi-Fi
4. Введите IP-адрес другого устройства
5. Нажмите синхронизировать

### Google Sheets синхронизация (необязательно)

Синхронизация с вашей таблицей есть на **Desktop и Android**. КПК в Google напрямую не ходит.

1. Разверните свой Apps Script по [GOOGLE_SYNC.md](GOOGLE_SYNC.md).
2. На Desktop: **Обмен → Google: мастер** (или **Настройки → центр Google Sync**). Вставьте URL веб-приложения и `SYNC_TOKEN`.
3. На Android: **Данные → синхронизация Google** — те же URL и токен.
4. Выполните синхронизацию и подтвердите предпросмотр.

Wi-Fi-обмен (порт `45816`) — это отдельный канал между Android и КПК, не настройка Google.

## Импорт и экспорт

### Desktop версия

- **Excel**: импорт/экспорт .xlsx
- **CSV**: импорт/экспорт текстовых файлов
- **Google Sheets**: прямая синхронизация
- **ZIP**: полная резервная копия и восстановление

### Android версия

- **ZIP**: импорт/экспорт резервных копий
- **Поиск**: глобальный поиск по всем записям
- **Поделиться**: экспорт отчетов в текст или HTML

## Часто задаваемые вопросы

### Данные хранятся локально?

Да, все данные хранятся только на вашем устройстве. Ничто не передается третьим лицам без вашего согласия.

### Могу ли я использовать приложение без Google?

Да. Журнал хранится на устройстве. Google Таблицы — необязательный обмен для Desktop и Android. КПК обходится копией или Wi-Fi с телефоном.

### Как перенести данные между устройствами?

Между Android и КПК — синхронизация по Wi-Fi или папка/ZIP. На компьютер — ZIP, папка `.dat`, Excel или CSV (Desktop), либо Google Таблицы с Android и Desktop.

### Могу ли я экспортировать данные?

Да:
- Desktop: Excel, CSV, HTML, ZIP
- Android: ZIP и текст/HTML отчёта
- КПК: папка копии, текст и HTML отчёта

## Решение проблем

### Приложение не запускается

**На Desktop:**
- Убедитесь, что установлен .NET Framework 4.8

**На Android:**
- Убедитесь, что Android 6.0 или выше
- Дайте необходимые разрешения при запросе

**На КПК:**
- Убедитесь, что установлена .NET Compact Framework 3.5
- Перезагрузите устройство

### Данные не синхронизируются

- Проверьте подключение Wi-Fi
- Убедитесь, что оба устройства в одной сети
- На Desktop: проверьте правильность URL Google Apps Script

### Как восстановить данные из резервной копии?

- Android: **Данные → Восстановить копию** или импорт ZIP.
- КПК: **Данные → Восстановить копию** из памяти устройства или с карты.
- Desktop: мастер **Импорт…** (ZIP, папка `.dat`, CSV или Excel).
