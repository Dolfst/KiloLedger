# Alfa 156 Desktop

ПК-приложение с тем же логотипом и стилем, что КПК и Android.

## Запуск

`dist/Alfa156-Desktop/Alfa156.Desktop.exe` (нужен .NET Framework 4.8)

## Возможности

- Папка `.dat` / ZIP Android↔КПК (включая `cars-meta.dat`, `templates.dat`, `Receipts/`)
- Excel `.xlsx` импорт/экспорт (у заправок колонки «Полный_бак», «Цель»)
- CSV для Google Sheets
- Импорт Google по ссылке (формат «Деньги»)
- **Синхронизация Google** через Apps Script (`../google-sync/`)
- Фильтры на вкладках Заправки / Ремонт / Прочие / Коммуналка (авто, период, поиск, категория, цель) — только вид, данные не удаляются
- Шаблоны записей («Из шаблона» / «Сохранить шаблон») и авто по умолчанию на вкладке Сводка
- Глобальный поиск; проверка пробега; дубликаты; проверка данных
- Сводка: график 12 мес.; итоги за год; бюджет; «Сравнить периоды»; «Сохранить сводку…»
- Вкладка Автомобили: год, госномер, VIN, бак, заметка (`cars-meta.dat`)
- Версия в заголовке окна

## Сборка

```bat
msbuild Alfa156.Desktop.csproj /p:Configuration=Release
```
