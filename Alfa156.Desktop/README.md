# Alfa 156 Desktop

ПК-приложение с тем же логотипом и стилем, что КПК и Android.

## Запуск

`dist/Alfa156-Desktop/Alfa156.Desktop.exe` (нужен .NET Framework 4.8)

## Возможности

- Папка `.dat` / ZIP Android↔КПК (включая `Receipts/` с фото чеков)
- Excel `.xlsx` импорт/экспорт (у заправок колонка «Полный_бак»)
- CSV для Google Sheets
- Импорт Google по ссылке (формат «Деньги»)
- **Синхронизация Google** через Apps Script (`../google-sync/`)
- Фильтры на вкладках Заправки / Ремонт / Прочие / Коммуналка (период, поиск, категория) — только вид, данные не удаляются
- Глобальный поиск по комментариям/названиям (поле в панели + диалог); проверка пробега при сохранении и правке км
- Google Sync включает прочие расходы (`Прочие {авто}`, `Кат. прочих`) с Apps Script 1.17+
- Сводка: график расходов за 12 месяцев; валюта (`settings.dat`); «Сохранить сводку…» → `.txt`; кнопка «Фото чека»
- Дубликаты (панель инструментов): группы по ключу/содержанию при разных id; удаление лишних
- Версия в заголовке окна

## Сборка

```bat
"%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\MSBuild.exe" Alfa156.Desktop.csproj /p:Configuration=Release
```
