# Alfa 156 Desktop

ПК-приложение с тем же логотипом и стилем, что КПК и Android.

## Запуск

`dist/Alfa156-Desktop/Alfa156.Desktop.exe` (нужен .NET Framework 4.8)

## Возможности

- Папка `.dat` / ZIP Android↔КПК (включая `cars-meta.dat`, `templates.dat`, `reminders.dat`, `Receipts/`)
- **Мастер «Импорт…»**: ZIP / папка `.dat` / CSV / Excel → предпросмотр счётчиков → `Safety_` и применение
- Excel `.xlsx` импорт/экспорт (у заправок колонки «Полный_бак», «Цель»)
- CSV для Google Sheets; **Шаблоны CSV** (пустые заголовки fuel/repairs/expenses)
- Импорт Google по ссылке (формат «Деньги»); **Синхронизация Google** через Apps Script (`../google-sync/`)
- Фильтры на вкладках Заправки / Ремонт / Прочие / Коммуналка (период, поиск, категория, цель) — только вид
- Глобальный поиск; проверка пробега; дубликаты; проверка данных
- Вкладка Автомобили: паспорт (`cars-meta.dat`); избранный авто (`default_car`)
- Шаблоны (`templates.dat`): «Из шаблона» / «Сохранить как шаблон»; напоминания по дате (`reminders.dat`)
- **Быстрая заправка** на панели инструментов: авто, пробег, литры, стоимость, авто цена/л, полный бак
- Сводка: график 12 мес.; итоги за год; цель заправки; бюджет; «Сравнить периоды»; оценка пробега (км/день и срок до ТО); «Лента авто»; «Сохранить сводку…»
- Версия в заголовке окна

## Сборка

```bat
"%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\MSBuild.exe" Alfa156.Desktop.csproj /p:Configuration=Release
```
