# Google Sheets синхронизация

KiloLedger поддерживает двустороннюю синхронизацию с Google Sheets на **Desktop** и **Android**.

> Подробная иллюстрированная инструкция также находится в [`google-sync/README.md`](google-sync/README.md).

## Как это работает

```text
KiloLedger Desktop / Android ←→ Google Apps Script ←→ Google Sheets
```

Приложение синхронизирует данные о расходах с вашей Google Таблицей через собственный Apps Script, который вы разворачиваете на своём аккаунте Google.

## Требования

- Google аккаунт
- Доступ к Google Sheets
- KiloLedger Desktop (1.37.0 и выше) или KiloLedger Android

## Пошаговая инструкция

### Шаг 1: Создайте Google Таблицу

1. Откройте [Google Sheets](https://sheets.google.com)
2. Создайте новую таблицу (или откройте уже существующую)
3. При необходимости скопируйте **ID таблицы** из адресной строки браузера — часть ссылки между `/d/` и `/edit`:
   ```text
   https://docs.google.com/spreadsheets/d/ЗДЕСЬ_ИД_ТАБЛИЦЫ/edit
   ```

![ID таблицы в адресной строке Google Таблицы](google-sync/screenshots/scr%20%282%29.png)

### Шаг 2: Создайте Apps Script

1. В Google Sheets откройте меню **Расширения → Apps Script**
2. Удалите код по умолчанию (`function myFunction() { }`)

![Пустой проект Apps Script с кодом по умолчанию](google-sync/screenshots/scr%20%283%29.png)

3. Скопируйте весь код из [`google-sync/KiloLedgerSync.gs`](google-sync/KiloLedgerSync.gs)
4. Вставьте код в редактор `Код.gs` и сохраните проект (значок дискеты или `Ctrl+S`)

![Редактор Apps Script со вставленным кодом KiloLedgerSync.gs](google-sync/screenshots/scr%20%284%29.png)

### Шаг 3: Настройте секретный токен (`SYNC_TOKEN`)

1. В левой панели редактора Apps Script откройте **⚙ Настройки проекта** (*Project Settings*) и прокрутите до раздела **Свойства скрипта** (*Script properties*)

![Раздел Свойства скрипта в настройках проекта](google-sync/screenshots/scr%20%285%29.png)

2. Нажмите **«Добавить свойство скрипта»**, добавьте `SYNC_TOKEN` с любым придуманным вами надёжным паролем и нажмите **«Сохранить свойства скрипта»**

![Заполненное свойство SYNC_TOKEN](google-sync/screenshots/scr%20%286%29.png)

3. Если скрипт создан отдельно (не через `Расширения → Apps Script` из таблицы), добавьте ещё свойство `SPREADSHEET_ID` с ID таблицы из Шага 1 и снова нажмите **«Сохранить свойства скрипта»**

![Добавление свойства SPREADSHEET_ID](google-sync/screenshots/scr%20%287%29.png)

### Шаг 4: Разверните как веб-приложение

1. Нажмите синюю кнопку **«Начать развертывание» → «Новое развертывание»** (*Deploy → New deployment*)

![Начать развертывание — Новое развертывание](google-sync/screenshots/scr%20%288%29.png)

2. Нажмите на шестерёнку рядом с **«Выберите тип»** и выберите **«Веб-приложение»** (*Web app*)

![Выбор типа развертывания Веб-приложение](google-sync/screenshots/scr%20%289%29.png)

3. Заполните параметры:
   - **Запуск от имени**: **От моего имени** (*Me*)
   - **У кого есть доступ**: **Все** (*Anyone*)
4. Нажмите **«Начать развертывание»**

![Параметры развертывания веб-приложения](google-sync/screenshots/scr%20%2810%29.png)

5. При первом развертывании пройдите подтверждение доступа Google:
   - В окне *«Google не проверил это приложение»* нажмите **«Дополнительно»** слева внизу
   - Нажмите **«Перейти к проекту … (небезопасно)»**
   - Нажмите **«Продолжить»**, разрешив доступ к Google Sheets

![Окно Google не проверил это приложение — нажмите Дополнительно](google-sync/screenshots/scr%20%2811%29.png)

![Нажмите Перейти к проекту (небезопасно)](google-sync/screenshots/scr%20%2812%29.png)

![Подтверждение доступа — кнопка Продолжить](google-sync/screenshots/scr%20%2813%29.png)

6. В окне результата скопируйте **URL** из раздела **«Веб-приложение»** (не «Идентификатор развертывания»!) и нажмите **«Готово»**.

Пример URL:
```text
https://script.google.com/macros/s/AKfycb.../exec
```

![Готовое развертывание и копирование URL веб-приложения](google-sync/screenshots/scr%20%281%29.png)

### Шаг 5: Настройте Desktop приложение

1. Откройте **KiloLedger Desktop**
2. Перейдите в **Обмен ▾ → Google: мастер** (или **Настройки → Центр Google Sync → Google: мастер** / **Google: настройка**)
3. Вставьте **URL веб-приложения** из Шага 4 и **SYNC_TOKEN** из Шага 3
4. Нажмите **«Проверить подключение»** (в мастере) и **«Готово» / «ОК»**

### Шаг 6: Первая синхронизация

1. Нажмите **Обмен ▾ → Синхронизация Google**
2. Сначала выполнится загрузка данных из Google Sheets (**pull**)
3. Подтвердите изменения в окне предпросмотра — локальные записи отправятся в Google Sheets (**push**)

## Структура Google Таблицы

Apps Script автоматически создаёт следующие листы в Google Sheets:

- **Заправки {авто}**: заправки
- **Ремонт {авто}**: ремонт и ТО
- **Прочие {авто}**: прочие расходы
- **Коммунальные**: коммунальные платежи
- **Справочник**: категории ремонта
- **Кат. прочих**: категории прочих расходов

## Обновление скрипта

После обновления кода [`google-sync/KiloLedgerSync.gs`](google-sync/KiloLedgerSync.gs) обязательно сделайте **Начать развертывание → Управление развертываниями → Изменить → Новая версия → Начать развертывание**, иначе на сервере останется старая версия скрипта.

## Безопасность

- Синхронизация работает только через ваш Google аккаунт и ваш собственный скрипт
- Данные не передаются третьим лицам
- **Никогда не публикуйте** свой `SYNC_TOKEN`, URL веб-приложения и файл `%AppData%\KiloLedger\google-sync.json`
