# Google Sheets синхронизация

Alfa 156 поддерживает двусторонню синхронизацию с Google Sheets на **Desktop** версии.

## Как это работает

```
Alfa 156 Desktop ←→ Google Apps Script ←→ Google Sheets
```

Приложение синхронизирует данные о расходах с Google Таблицей через кастомный Apps Script, который вы развернете на своем Google аккаунте.

## Требования

- Google аккаунт
- Доступ к Google Sheets
- Desktop версия Alfa 156 (1.37.0 и выше)

## Пошаговая инструкция

### Шаг 1: Создайте Google Sheet

1. Откройте [Google Sheets](https://sheets.google.com)
2. Создайте новую таблицу (или откройте вашу существующую таблицу)

### Шаг 2: Создайте Apps Script

1. В Google Sheets: Меню → Расширения → Apps Script
2. Удалите код по умолчанию
3. Скопируйте код из [`google-sync/Alfa156Sync.gs`](google-sync/Alfa156Sync.gs)
4. Вставьте код в редактор и сохраните проект (Ctrl+S)

### Шаг 3: Настройте секретный токен (`SYNC_TOKEN`)

1. В редакторе Apps Script откройте **Project Settings (⚙)** → **Script properties**
2. Добавьте свойство `SYNC_TOKEN` с любым надёжным паролем (придуманным вами)
3. Если скрипт создан отдельно (не через `Расширения → Apps Script` из таблицы), добавьте ещё свойство `SPREADSHEET_ID` с ID таблицы из URL `https://docs.google.com/spreadsheets/d/[ID]/edit`

### Шаг 4: Разверните как веб-приложение

1. Нажмите кнопку "Deploy" (Развернуть)
2. Выберите "New deployment"
3. Тип: выберите "Web app"
4. Выполнить как: ваш Google аккаунт
5. Доступ для: все имеющие ссылку
6. Нажмите Deploy
7. **Скопируйте URL развернутого приложения** (вам понадобится)

Пример URL:
```
https://script.google.com/macros/d/YOUR_DEPLOYMENT_ID/useweb
```

### Шаг 5: Настройте Desktop приложение

1. Откройте Alfa 156 Desktop
2. Меню → Данные → Синхронизация по Wi-Fi
3. Введите URL из Шага 4
4. Нажмите "Получить токен"
5. Скопируйте токен и вставьте в приложение
6. Нажмите ОК

### Шаг 6: Первая синхронизация

1. Меню → Данные → Синхронизация по Wi-Fi
2. Нажмите "Синхронизировать"
3. Приложение загрузит данные из Google Sheets
4. При наличии новых данных они будут добавлены в локальную базу

## Как работает синхронизация

### Загрузка с Google Sheets

При нажатии "Синхронизировать":
1. Приложение подключается к Google Apps Script
2. Получает данные из Google Sheets
3. Объединяет с локальными данными
4. Сохраняет результат локально

### Загрузка в Google Sheets

После синхронизации:
1. Новые записи отправляются в Google Sheets
2. Google Sheets обновляет таблицу
3. Данные остаются синхронизированными

## Структура Google Sheet

Apps Script создает следующие листы в Google Sheets:

- **Vehicles**: автомобили
- **Fuel**: заправки
- **Repairs**: ремонт и ТО
- **Utilities**: коммунальные платежи
- **Expenses**: прочие расходы
- **Sync Log**: лог синхронизации (для отладки)

## Безопасность

### Данные не передаются третьим лицам

- Синхронизация работает только через ваш Google аккаунт
- Google Apps Script запускается в вашем аккаунте
- Данные не передаются разработчику Alfa 156

### Как защитить доступ

1. **Защитите Google Sheet**:
   - Меню → Защита → Защитить лист
   - Выберите, кого уведомить об изменениях

2. **Управляйте доступом к Apps Script**:
   - В Apps Script: Меню → Настройки проекта
   - Измените Параметры доступа

3. **Регулярно проверяйте логи**:
   - Лист "Sync Log" содержит историю синхронизаций

## Решение проблем

### "Не удалось подключиться к скрипту"

**Причины:**
- URL скрипта неправильный
- Скрипт не развернут как веб-приложение
- Скрипт удален или переразвернут

**Решение:**
1. Проверьте URL в настройках
2. Перейдите в Apps Script проект
3. Заново разверните как веб-приложение (шаг 4 выше)
4. Скопируйте новый URL в приложение

### "Не найдена таблица"

**Причины:**
- ID таблицы неправильный
- Таблица удалена
- Нет доступа к таблице

**Решение:**
1. Создайте новую таблицу с названием "Alfa156"
2. Скопируйте правильный ID из URL
3. Обновите SPREADSHEET_ID в Apps Script
4. Переразверните скрипт

### Данные не синхронизируются

**Решение:**
1. Проверьте интернет соединение
2. Нажмите ОК в диалоге синхронизации
3. Проверьте лист "Sync Log" для ошибок
4. Если проблема сохраняется - переразверните скрипт (шаг 4)

## Автоматизация (опционально)

Вы можете настроить автоматическую синхронизацию:

1. В Apps Script: Меню → Триггеры
2. Нажмите "+ Создать триггер"
3. Выберите функцию `synchronizeFromMobile`
4. Триггер: "По расписанию" (например, каждый час)

## Экспорт в Excel

После синхронизации вы можете экспортировать данные:

1. В Google Sheets: выберите нужный лист
2. Скачайте как Excel файл (.xlsx)
3. Откройте в Microsoft Excel

## Отключение синхронизации

Если вы больше не хотите синхронизировать:

1. В Alfa 156 Desktop: удалите URL скрипта из настроек
2. (Опционально) В Apps Script: удалите развернутый скрипт

**Важно**: локальные данные в приложении не удалятся.
