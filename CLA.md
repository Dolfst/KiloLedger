A **Contribution** is any original work of authorship, including a modification or addition to an existing work, that you submit to the Project Owner for inclusion in KiloLedger. ## 8. How you agree

You agree to this Agreement for a Contribution when you submit it and either:

- tick the Contributor License Agreement checkbox in the pull request template, or
- write in the pull request that you agree to the KiloLedger Contributor License Agreement ([CLA.md](CLA.md)).

That agreement covers the Contribution in that pull request. A later Contribution needs its own agreement in the same way, unless you and the Project Owner have a separate signed CLA that already covers future submissions.

Marking a pull request “Not a Contribution” for a specific file or comment keeps that marked material outside this Agreement. Do not mark the code you want merged.
