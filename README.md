# Alfa 156 — учёт расходов автомобиля

Проект содержит приложение для HP iPAQ 214 под Windows Mobile и отдельное Android-приложение для просмотра и переноса данных. Облачной синхронизации между устройствами пока нет: данные передаются резервными копиями.

## Проекты

- `Alfa156/Alfa156.sln` — исходное приложение для Pocket PC, Windows Mobile и .NET Compact Framework 3.5.
- `Alfa156.Android/Alfa156.Android.csproj` — Android-приложение для телефонов, включая Samsung Galaxy S23+.

Android-приложение позволяет импортировать копию КПК, просматривать заправки, ремонт/ТО и коммунальные платежи, а также экспортировать данные в ZIP. Записи в Android-версии пока только для просмотра.

## Данные и резервные копии КПК

Рабочие файлы на КПК:

```text
\My Documents\Alfa156\
  cars.dat
  fuel.dat
  repairs.dat
  utilities.dat
```

Формат файлов текстовый UTF-8; строки разделены переводами строк, поля — символом `|`. Обратная косая черта экранирует `|` и саму себя.

В приложении на КПК откройте **Данные → Создать копию на SD**. Копии сохраняются отдельными папками по дате и времени:

```text
\Storage Card\Alfa156_Backups\ГГГГММДД_ЧЧММСС\
```

Перед восстановлением приложение сохраняет текущие данные ещё одной копией на карту. Для защиты от потери и КПК, и карты памяти регулярно переносите `Alfa156_Backups` на компьютер через ActiveSync.

## Перенос копии на Android

1. Создайте копию на SD-карте КПК.
2. Через ActiveSync скопируйте папку нужной копии на компьютер.
3. Перенесите её на телефон или создайте ZIP-архив папки на компьютере.
4. В Alfa 156 на Android нажмите **Импорт копии**.
   - Для ZIP выберите архив.
   - Для папки с КПК можно выбрать все четыре файла `.dat` за один раз.
5. Выберите раздел **Заправки**, **Ремонт** или **Коммунальные**, чтобы просмотреть записи.

При импорте приложение проверяет наличие всех файлов и формат строк. Если на телефоне уже есть данные, перед заменой они сохраняются во внутреннюю резервную копию приложения.

Чтобы выгрузить данные с Android, нажмите **Экспорт ZIP** и выберите место сохранения, например «Загрузки» или Google Drive. Чтобы перенести такой ZIP обратно на КПК, распакуйте его на компьютере и скопируйте четыре `.dat` в новую папку внутри `\Storage Card\Alfa156_Backups\`; затем используйте **Данные → Восстановить копию**.

> Копия только на карте памяти не защищает от потери самой карты или КПК вместе с ней. Храните ещё одну копию на компьютере или в облачном диске. Удаление Android-приложения также удалит его локальные данные, поэтому регулярно используйте экспорт ZIP.

## Сборка приложения для КПК

Нужны Visual Studio 2008, Windows Mobile 5.0 Pocket PC SDK и .NET Compact Framework 3.5. Откройте `Alfa156/Alfa156.sln` и соберите конфигурацию **Release**. Для установки на устройство используйте CAB-проект Visual Studio или скопируйте собранные файлы согласно настройке проекта.

## Сборка Android APK

Нужны .NET 10 SDK, JDK 17 и workload Android для .NET. Если Android SDK ещё не установлен, установите зависимости (укажите абсолютные пути):

```sh
dotnet workload install android
dotnet build Alfa156.Android/Alfa156.Android.csproj \
  -t:InstallAndroidDependencies -f net10.0-android \
  -p:AndroidSdkDirectory="/полный/путь/android-sdk" \
  -p:JavaSdkDirectory="/полный/путь/jdk" \
  -p:AcceptAndroidSDKLicenses=True
```

После установки задайте переменные `ANDROID_HOME` и `JAVA_HOME`, затем соберите APK:

```sh
dotnet build Alfa156.Android/Alfa156.Android.csproj -c Debug
```

Готовый APK: `Alfa156.Android/bin/Debug/net10.0-android/com.alfa156.mobile-Signed.apk`. На Samsung передайте его на телефон, откройте через «Мои файлы» и разрешите установку из этого источника, если Android попросит.

## Текущее ограничение

Передача данных сейчас выполняется файлами вручную. Общего сервера и автоматической синхронизации между КПК, Android и компьютером в проекте пока нет.
