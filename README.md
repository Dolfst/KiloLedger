# Alfa 156 — учёт расходов автомобиля

Приложения для **КПК (Windows Mobile)**, **Android** и **ПК (Windows)** с общим форматом данных, общим стилем и единым логотипом (красный круг с машинкой).


## Что нового в 1.13.0

- **Фильтры на Desktop** для вкладок Заправки, Ремонт, Прочие и Коммуналка: период с/по, текст, для ремонта/прочих — категория; кнопки «Применить» / «Сбросить». Фильтр только скрывает строки в таблице — данные и PullAll/сохранение не теряют скрытые записи.
- **Полный бак** у заправок: опциональное поле `fullTank` (`1` по умолчанию / `0` частичная) после комментария, перед id: `date|car|km|liters|cost|price|comment|fullTank|id`. Старые строки без флага = полный бак. Расход л/100 км считается только между полными баками (частичная заправка не замыкает интервал) — на Android, КПК и в деталях записи. Чекбокс «Полный бак» в формах добавления (по умолчанию включён); колонка на Desktop. Excel/CSV: колонка «Полный_бак».
- Версия в заголовке Desktop и пункте «О программе» (Android: Данные; КПК: Данные).

## Что нового в 1.12.0

- **Wi‑Fi sync v2:** после проверки 6‑значного кода полезная нагрузка обфусцируется сессионным ключом (SHA1 от кода + соль приложения, XOR-поток). Старые клиенты получают «Обновите Alfa 156 на обоих устройствах до 1.12+». По-прежнему используйте доверенную точку доступа.
- **Мастер Google Sync** на Desktop («Google: мастер»): инструкции → URL/SYNC_TOKEN → проверка pull. Расширенная «Google: настройка» сохранена. На Android — краткая справка в настройках Google.

## Что нового в 1.11.0

- **Прочие расходы** автомобиля: страховка, техосмотр, штрафы, мойка, парковка и свои категории (`expenses.dat` / `expense-categories.dat`). Учитываются в сводке и в стоимости км.
- **Настраиваемые интервалы ТО** масла и ремня ГРМ (`settings.dat`); UI на Android (Данные → Интервалы ТО), КПК (Действия → Интервалы ТО) и Desktop (вкладка Сводка).
- Excel/CSV: листы/файлы «Прочие» и «Кат. прочих». Google Sheets пока без прочих расходов — используйте ZIP/`.dat`/Excel.
- Wi‑Fi payload 1.11+ включает новые файлы; синхронизируйте устройства одной мажорной версии 1.11+.

## Проекты

- `Alfa156/Alfa156.sln` — Pocket PC / Windows Mobile, .NET Compact Framework 3.5
- `Alfa156.Android/Alfa156.Android.csproj` — Android
- `Alfa156.Desktop/Alfa156.Desktop.csproj` — ПК (.NET Framework 4.8): Excel, CSV, Google Sheets
- `google-sync/` — Apps Script для двусторонней синхронизации с Google Таблицей
- `branding/` — общий логотип и описание стиля (`BrandTheme.md`)
- `VERSION` — единый номер версии приложения (источник правды для имён файлов и сборок)
- `dist/download/` — готовые сборки: `Alfa156-<version>.apk`, `Alfa156-<version>-Desktop.exe`, `Alfa156-<version>-KPK.exe` / `.zip`
- `dist/Alfa156-Desktop/` — готовый `Alfa156.Desktop.exe`

На всех платформах: автомобили, заправки, ремонт/ТО, прочие расходы, коммунальные, фильтры, категории, сводка, интервалы ТО. Android — ZIP и Wi‑Fi; КПК — резервные копии и Wi‑Fi; ПК — Excel/Google.

## Синхронизация

```text
КПК  ←── Wi‑Fi / точка доступа телефона ──→  Android  ←── Apps Script ──→  Google Sheets  ←→  ПК
```

### КПК ↔ Android (в том числе когда телефон раздаёт Wi‑Fi)

1. На Android включите **точку доступа** (или общую Wi‑Fi сеть).
2. **Данные → Синхронизация по Wi‑Fi** — смотрите IP с пометкой «точка доступа» (часто `192.168.43.1`) и код.
3. На КПК подключитесь к этой сети, затем **Данные → Синхронизация по Wi‑Fi**, введите IP и код.

Интернет на КПК не нужен. Порт: `45816`.

### Android / ПК ↔ Google Sheets

См. `google-sync/README.md`. На Desktop удобнее **Google: мастер** (пошагово + проверка связи). Кратко: вставить `Alfa156Sync.gs` в таблицу, задать `SYNC_TOKEN`, опубликовать Web App, указать URL в приложении.

КПК в Google напрямую не ходит — только через Android или ZIP/папку через ПК.

## Данные и резервные копии КПК

Рабочие файлы на КПК:

```text
\My Documents\Alfa156\
  cars.dat
  fuel.dat
  repairs.dat
  utilities.dat
  repair-categories.dat
  expenses.dat
  expense-categories.dat
  settings.dat
  deleted.dat
```

Формат файлов текстовый UTF-8; строки разделены переводами строк, поля — символом `|`. Обратная косая черта экранирует `|` и саму себя. У каждой записи (авто, заправка, ремонт, коммуналка, прочий расход, категория ремонта/прочих) в конец строки пишется стабильный id (`c_`/`f_`/`r_`/`u_`/`e_`/`k_`/`p_` + 8 hex). Старые файлы без id читаются; id назначаются при сохранении и синхронизации. `deleted.dat` — tombstones удалений (`тип|id|UTC`), список обрезается до последних 5000. `repair-categories.dat` и `expense-categories.dat` содержат категории (+ id); при отсутствии создаются списки по умолчанию. `fuel.dat` — `date|car|km|liters|cost|[price]|[comment]|[fullTank]|[id]` (`fullTank`: `1` полный / `0` частичный; без поля = полный). `expenses.dat` — прочие расходы автомобиля (`date|car|category|name|sum|comment|id`). `settings.dat` — интервалы ТО (`oil_interval`, `oil_warn`, `belt_interval`, `belt_warn`).

Для локальной копии в памяти КПК откройте **Данные → Создать копию в памяти КПК**. Такие копии сохраняются в `\My Documents\Alfa156_LocalBackups\`; пункт **Восстановить копию из памяти КПК** восстанавливает выбранную копию и сначала сохраняет текущие данные рядом.

Для копии на SD-карте откройте **Данные → Создать копию на SD**. Копии сохраняются отдельными папками по дате и времени:

```text
\Storage Card\Alfa156_Backups\ГГГГММДД_ЧЧММСС\
```

Перед восстановлением копии с SD приложение сохраняет текущие данные ещё одной копией на карту. Для защиты от потери и КПК, и карты памяти регулярно переносите `Alfa156_Backups` на компьютер через ActiveSync.

## Перенос копии на Android

1. Создайте копию на SD-карте КПК.
2. Через ActiveSync скопируйте папку нужной копии на компьютер.
3. Перенесите её на телефон или создайте ZIP-архив папки на компьютере.
4. В Alfa 156 на Android откройте **Данные → Импорт копии**.
   - Для ZIP выберите архив.
   - Для папки с КПК выберите файлы `.dat` за один раз. В старых копиях будет четыре–пять файлов, в 1.10+ — до шести (`deleted.dat`).
5. Выберите раздел **Заправки**, **Ремонт** или **Коммунальные**, чтобы просмотреть записи.

При импорте приложение проверяет наличие всех файлов и формат строк, затем показывает автомобили и число записей для проверки. Замена выполняется только после подтверждения; если на телефоне уже есть полный набор данных, перед заменой он сохраняется во внутреннюю резервную копию приложения.

## Синхронизация Android ↔ КПК без интернета

1. Включите на телефоне **точку доступа** и подключите к ней КПК — или посадите оба устройства в одну Wi‑Fi сеть. Интернет не нужен.
2. На Android: **Данные → Синхронизация по Wi-Fi**. Используйте IP с пометкой «точка доступа» (часто `192.168.43.1`) и шестизначный код.
3. На КПК: **Данные → Синхронизация по Wi-Fi**, введите этот IP и код. Поле IP запоминает последний адрес.
4. При конфликте одной записи Android предложит оставить версию телефона или КПК.
5. После завершения объединённый набор записей окажется на обоих устройствах. Перед установкой Android сохраняет внутреннюю резервную копию, КПК — копию в `\My Documents\Alfa156_SyncSafety_ГГГГММДД_ЧЧММСС`.

Синхронизация (с 1.10.0) сопоставляет записи **сначала по стабильному id**, иначе по естественным ключам (заправка: дата+авто+пробег; ремонт: дата+авто+пробег+категория+товар; прочий расход: дата+авто+категория+название; коммуналка: месяц; авто/категория: название). Удаления передаются через `deleted.dat` (tombstones, тип `expense` для прочих): удалённый id не воскресает при обмене. Wi‑Fi payload с 1.11.0 также включает `expenses.dat`, `expense-categories.dat`, `settings.dat`. С 1.12.0 протокол Wi‑Fi — `ALFA156SYNC2` с обфускацией сессии: Android и КПК должны быть 1.12+. После sync показывается краткий журнал. **Google Sheets** по-прежнему без прочих расходов: id остаются в локальных `.dat`/ZIP. Перед первой синхронизацией рекомендуется резервная копия.

## Работа с записями на Android

- Если данных ещё нет, откройте **Данные → Начать с нуля**, укажите первый автомобиль — дальше можно сразу добавлять заправки, ремонт и коммунальные без импорта с КПК. Либо используйте **Импорт копии**.
- Выберите автомобиль в списке **Авто**; через **Добавить** можно завести ещё один автомобиль.
- Переключайтесь между заправками, ремонтом/ТО и коммунальными платежами. Нажмите запись, чтобы увидеть подробности; для изменения или удаления выберите запись и нажмите соответствующую кнопку. Удаление запрашивает подтверждение.
- **Добавить** открывает форму: для заправки выберите дату, укажите пробег, литры и стоимость; автомобиль выбран заранее. На КПК и Android автоматически подставляется последний зарегистрированный пробег выбранного автомобиля, его можно изменить. Чекбокс «Полный бак» по умолчанию включён — снимите его для частичной заправки. Для ремонта/ТО укажите дату, автомобиль, пробег, категорию, товар/деталь, наименование, количество, сумму и комментарий. Расход топлива в л/100 км показывается только для полной заправки при наличии предыдущей **полной** заправки с меньшим пробегом.
- Коммунальная запись содержит месяц и суммы по категориям: коммунальные платежи, электричество, газ, стационарный телефон, домашний интернет, налог на аренду и аренда жилья. Нужно указать хотя бы одну сумму; для каждого месяца допускается одна запись. Даты и месяцы выбираются календарём, числовые поля проверяются при сохранении.
- Фильтры доступны для заправок и ремонта/ТО. Для заправок можно задать период и искать по пробегу, литрам или стоимости; для ремонта/ТО — выбрать категорию, период и искать по названию/товару. **Сбросить фильтр** очищает фильтр текущего раздела.
- В разделе **Ремонт и ТО** откройте **Категории**, чтобы добавить, переименовать или удалить категорию. Переименование обновляет категории в старых записях. Удалить категорию с записями нельзя: сначала измените категорию у этих записей. Список переносится между Android и КПК в резервной копии и при Wi-Fi-синхронизации.
- **Сводка и ТО** показывает расходы на топливо и ремонт выбранного автомобиля, разбивку ремонта по категориям, примерные учтённые расходы на километр, помесячные расходы за последние 12 месяцев и сравнение суммарных расходов на топливо и ремонт по автомобилям. Расходы на километр — ориентир по внесённым затратам и разнице между минимальным и максимальным зарегистрированным пробегом; он не учитывает пропущенные записи и коммунальные платежи. Коммунальные расходы показываются за весь период. Для напоминаний о замене масла и ремня ГРМ выводятся дата и пробег записи, по которой рассчитан интервал; интервалы составляют 10 000 км и 60 000 км соответственно.
- Локальные копии и восстановление доступны на обоих устройствах: на Android — **Данные → Копия на телефоне** и **Данные → Восстановить копию**, на КПК — **Данные → Создать копию в памяти КПК** и **Восстановить копию из памяти КПК**. Перед восстановлением текущие данные тоже сохраняются.

На КПК в разделе **Сводка и ТО** доступны те же показатели: расходы по выбранному автомобилю, ремонт по категориям, приблизительные расходы на километр, расходы по месяцам за последние 12 месяцев, сравнение расходов на топливо и ремонт по автомобилям, текущий пробег и напоминания о ТО с датой и пробегом записи, по которой рассчитан интервал. Данные читаются из тех же файлов `.dat`, поэтому отдельная настройка или преобразование не требуется.

Фильтр заправок по периоду, пробегу, литрам и стоимости также доступен в меню **Действия** на КПК.

Чтобы выгрузить данные с Android, откройте **Данные → Экспорт ZIP** и выберите место сохранения, например «Загрузки» или Google Drive. Чтобы перенести такой ZIP обратно на КПК, распакуйте его на компьютере и скопируйте все пять `.dat` в новую папку внутри `\Storage Card\Alfa156_Backups\`; затем используйте **Данные → Восстановить копию**.

> Копия только на карте памяти не защищает от потери самой карты или КПК вместе с ней. Храните ещё одну копию на компьютере или в облачном диске. Удаление Android-приложения также удалит его локальные данные, поэтому регулярно используйте экспорт ZIP.

## Сборка приложения для КПК

На GitHub Actions (workflow **KPK EXE**) или локально без полного WM SDK:

```powershell
powershell -ExecutionPolicy Bypass -File build/build-kpk.ps1 -Configuration Release
```

Нужны справочные сборки в `build/cf35/WindowsCE` (уже в репозитории) и `ResGen.exe` / `csc.exe` (.NET Framework).  
Альтернатива: Visual Studio 2008 + Windows Mobile SDK + .NET CF 3.5, открыть `Alfa156/Alfa156.sln`, конфигурация **Release**.

## Сборка Android APK

Нужны .NET 10 SDK, JDK 17 и workload Android для .NET. Если Android SDK ещё не установлен, установите зависимости (укажите абсолютные пути):

```sh
dotnet workload install android
dotnet build Alfa156.Android/Alfa156.Android.csproj \
  -t:InstallAndroidDependencies -f net10.0-android \
  -p:AndroidSdkDirectory="/полный/путь/android-sdk" \
  -p:JavaSdkDirectory="/полный/путь/jdk" \
  -p:AcceptAndroidSDKLicenses=True
```

После установки задайте переменные `ANDROID_HOME` и `JAVA_HOME`, затем соберите самостоятельный Release APK для ARM64 (сборки приложения включены внутрь файла):

```sh
dotnet build Alfa156.Android/Alfa156.Android.csproj -c Release \
  -p:RuntimeIdentifier=android-arm64
```

Готовый APK: `Alfa156.Android/bin/Release/net10.0-android/android-arm64/com.alfa156.mobile-Signed.apk`. На Samsung передайте его на телефон, откройте через «Мои файлы» и разрешите установку из этого источника, если Android попросит.

Текущая ARM64-сборка также хранится в `Alfa156.Android/Alfa156.apk` и включается в ZIP-архив репозитория. При обновлении Android-приложения замените этот файл новой Release-сборкой.

Если установка пишет «приложение не установлено» без обновления поверх старого: разрешите установку из браузера/«Мои файлы», скачайте APK заново (файл ~4 МБ) и ставьте на 64‑битный телефон (Samsung Galaxy S23+ и новее).

## Текущее ограничение

Синхронизация работает только между Android и КПК в одной локальной Wi-Fi сети; компьютер и Bluetooth-протокол не поддерживаются. После проверки 6‑значного кода полезная нагрузка обфусцируется сессионным ключом, производным от кода (протокол v2, Alfa 156 1.12+). Это не замена TLS: используйте доверенную точку доступа / сеть.
