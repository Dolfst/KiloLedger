# План улучшений Alfa 156

Этот план отражает состояние разработки и обновляется перед этапной публикацией.

## Выполнено

- Добавлен базовый [сравнительный анализ аналогов и долгосрочный бэклог](docs/competitive-analysis.md): Alfa 156 vs Drivvo, Fuelio, Simply Auto, aCar и Fuelly.
- Этап 1: версия 1.34.0 опубликована на GitHub для Android, Desktop и КПК.
- Этап 2: сборка КПК через Mono добавлена в smoke workflow.
- 1.34.0: усилена проверка стабильных ID и обнаружение дубликатов.
- 1.34.0: добавлены проверки пустых коммунальных записей и дубликатов месяцев.
- 1.34.0: усилена проверка паспортных данных автомобилей, заметок, напоминаний и шаблонов.
- 1.34.0: добавлена сборка КПК в Linux через Mono и справочные сборки CF 3.5.
- 1.34.0: расширен набор smoke-проверок для резервного копирования, бюджета и метаданных.
- 1.34.1: номер версии повышен во всех клиентах; Android versionCode теперь однозначно учитывает patch-версию.
- 1.34.1: ZIP/CSV импорт Desktop защищён проверками формата; старое восстановление КПК сохраняет фото чеков.
