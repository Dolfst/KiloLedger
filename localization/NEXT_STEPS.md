## Советы для продолжающего агента

1. **Используйте скрипты sed** для массовых замен (быстрее вручную)
2. **Добавляйте недостающие переводы** в JSON по мере необходимости
3. **Создавайте коммиты после каждого этапа** (важно для отката в случае проблем)
4. **Тестируйте** хотя бы основную функциональность после каждого этапа
5. **Оставляйте TODO комментарии** в коде для еще не локализированных строк

## Текущие лимиты

- Система работает с простыми строками (ключ → значение)
- Пока нет поддержки plurals или параметризованных строк
- Переводы загружаются из JSON файлов (можно расширить до базы данных)
