Эта ветка содержит работу по добавлению поддержки нескольких языков в приложение KiloLedger.

## Как использовать

### В коде C#

```csharp
using Alfa156.Localization;

// Получить переведенную строку
string title = L10n.Get("app.title");

// Получить текущий язык
string currentLang = L10n.GetLanguage();

// Изменить язык
L10n.SetLanguage("en");

// Получить список доступных языков
string[] languages = L10n.GetAvailableLanguages(); // ["ru", "en"]
```

### Добавить новую строку

1. Добавьте ключ и значение в `strings.ru.json`:
```json
{
  "my.new.key": "Новое значение"
}
```

2. Добавьте перевод в `strings.en.json`:
```json
{
  "my.new.key": "New value"
}
```

3. Используйте в коде:
```csharp
string text = L10n.Get("my.new.key");
```

### Добавить новый язык

1. Создайте новый файл `strings.{lang}.json` в папке `resources/`
2. Скопируйте структуру из `strings.ru.json`
3. Переведите все значения
4. Новый язык автоматически появится в `GetAvailableLanguages()`

## JSON формат

Файлы переводов используют простой JSON формат:

```json
{
  "category.subcategory.key": "Значение",
  "app.title": "KiloLedger",
  "button.ok": "ОК",
  "message.error": "Произошла ошибка"
}
```

**Правила именования ключей:**
- Используйте точечную нотацию (category.key)
- Первый уровень - категория (app, button, label, message, tab, menu)
- Вторые и последующие - специфика (title, ok, cancel и т.д.)

## Лимиты и ограничения

- Система работает без внешних зависимостей (только .NET)
- JSON парсер поддерживает простые строковые значения
- Для сложных форматов (plurals, gender) требуется расширение парсера
