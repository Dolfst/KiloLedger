## Что нужно перед началом

- Аккаунт Google (Gmail).
- Приложение **Alfa 156 Desktop** (версия 1.37.0 и выше) или **Alfa 156 Android**.
- Примерно 10–15 минут свободного времени.

> **Важно:** Синхронизация работает через вашу собственную таблицу Google Sheets. Приложение не имеет доступа к чужим таблицам, и вы не должны публиковать свои настройки в интернете.

---

## Шаг 1. Создайте Google Таблицу

1. Откройте [Google Sheets](https://sheets.google.com).
2. Нажмите **«Создать» → «Таблица»**.
3. Дайте таблице любое название, например `Alfa 156 — Данные`.
4. Скопируйте часть ссылки после `/d/` — это **ID таблицы**. Пригодится на шаге 3.

```
https://docs.google.com/spreadsheets/d/ЗДЕСЬ_ИД_ТАБЛИЦЫ/edit
```

![Empty Google Table with address bar](screenshots/empty_google_table.png)

---

## Шаг 2. Установите Apps Script

1. В своей таблице откройте меню **Расширения → Apps Script**.
2. Откроется редактор скриптов. Удалите весь код по умолчанию.
3. Скачайте файл [`Alfa156Sync.gs`](https://raw.githubusercontent.com/Dolfst/alfa/main/google-sync/Alfa156Sync.gs) из репозитория приложения.
4. Откройте файл в Блокноте, скопируйте всё содержимое и вставьте в редактор Apps Script.
5. Нажмите **Сохранить** (дискета) или `Ctrl + S`.
6. Назовите проект, например `Alfa156 Sync`.

![Apps Script editor with Alfa156Sync.gs code](screenshots/apps_script_editor.png)

## Шаг 3. Настройте свойства скрипта (SYNC_TOKEN)

1. В редакторе Apps Script нажмите значок шестерёнки **⚙ Project Settings** (настройки проекта).
2. Найдите раздел **Script properties**.
3. Нажмите **«Добавить свойство»** (Add property).
4. Введите:

   | Ключ | Значение |
   |------|----------|
   | `SYNC_TOKEN` | Придумайте любой надёжный пароль (например, `kJ7#mP2vL9`) |

   > Это **не ваш пароль от Google**, а секретный код, который вы придумываете сами. Он понадобится в приложении Alfa 156 для защиты соединения.

5. Если скрипт создан как отдельный проект (не через «Расширения → Apps Script» внутри таблицы), добавьте ещё одно свойство:

   | Ключ | Значение |
   |------|----------|
   | `SPREADSHEET_ID` | ID вашей таблицы (часть ссылки после `/d/` из шага 1) |

6. Нажмите **Сохранить**.

![Project Settings with filled fields](screenshots/project_settings.png)

## Шаг 4. Разверните как веб-приложение

1. Нажмите кнопку **Deploy** (вверху справа) → **New deployment**.
2. Выберите тип **Web app**.
3. Настройте параметры:

   | Параметр | Значение |
   |----------|----------|
   | Execute as | **Me** (я) |
   | Who has access | **Anyone** (любой, имеющий ссылку) |

   > Доступ «Anyone» нужен, чтобы приложение Alfa 156 могло обращаться к скрипту по URL без входа в Google.

4. Нажмите **Deploy**.
5. В открывшемся окне скопируйте **URL веб-приложения**. Он выглядит примерно так:

   ```
   https://script.google.com/macros/d/ABC123.../exec
   ```

6. Сохраните этот URL — он понадобится в приложении.

![New deployment window with parameters and copied URL](screenshots/new_deployment.png)

## Шаг 5. Настройте Alfa 156 Desktop

### Вариант А: через мастер (рекомендуется)

1. Запустите **Alfa 156 Desktop**.
2. Нажмите кнопку **«Google: мастер»** (в панели инструментов или в меню «Данные»).
3. Мастер проведет вас через три шага:
   - **Шаг 1.** Инструкция (этот README).
   - **Шаг 2.** Вставьте **URL веб-приложения** и **SYNC_TOKEN** (который придумали на шаге 3).
   - **Шаг 3.** Проверка подключения (pull).

### Вариант Б: ручная настройка

1. Нажмите кнопку **«Google: настройка»**.
2. В поле **URL веб-приложения** вставьте скопированный URL из шага 4.
3. В поле **Токен (SYNC_TOKEN)** введите придуманный пароль.
4. Нажмите **Сохранить**.

![Google Sync master window in Alfa 156 Desktop](screenshots/google_sync_master.png)

## Шаг 6. Первая синхронизация

1. Нажмите кнопку **«Синхронизация Google»**.
2. Пройдёт **pull** — загрузка данных из вашей таблицы Google. Если таблица новая и пустая, локальные данные не изменятся.
3. После подтверждения нажмите **push** — локальные данные из `.dat` файлов отправятся в таблицу.
4. Скрипт автоматически создаст нужные листы: `Заправки {авто}`, `Ремонт {авто}`, `Прочие {авто}`, `Коммунальные`, `Справочник`.

![Google Sync dialog in Alfa 156 Desktop](screenshots/google_sync_dialog.png)

## Для пользователей Android

1. Откройте **Alfa 156 Android**.
2. Перейдите в **Данные → Google: настройка**.
3. Вставьте те же **URL веб-приложения** и **SYNC_TOKEN**, что и на Desktop.
4. Нажмите **Сохранить**.
5. Используйте кнопку синхронизации Google в приложении.

![Google Sync settings screen in Alfa 156 Android](screenshots/android_sync_settings.png)

## Обновление Apps Script после правок

Если вы вносите изменения в файл `Alfa156Sync.gs` (например, после обновления приложения), обязательно переопубликуйте скрипт, иначе на сервере останется старая версия:

1. В редакторе Apps Script нажмите **Deploy → Manage deployments**.
2. Выберите ваше развертывание → **Edit**.
3. Нажмите **New version**.
4. Нажмите **Deploy**.

Без этого шага новые колонки или исправления не заработают.

## Конфликты и особенности

| Ситуация | Что происходит |
|----------|----------------|
| Запись есть только в Google | При sync она добавится локально |
| Запись есть только локально | Она уйдёт в Google при push |
| Одна и та же запись изменилась с обеих сторон | Приложение спросит, какую версию оставить |
| Локальные «лишние» записи | По умолчанию не удаляются |

### Важное ограничение про `id` и удаления
Локальные `.dat` файлы хранят стабильные идентификаторы записей и метки удаления (`deleted.dat`). В Google Sheets идентификаторы не записываются (матрица колонок не меняется), поэтому обмен с таблицей идёт по ключам (дата + автомобиль + сумма и т.п.). Надёжная передача удалений работает через **Wi-Fi (Android ↔ КПК)** и **ZIP/папку .dat**, а не через Google.

## Где хранятся настройки

Конфигурация синхронизации сохраняется здесь:

```
%AppData%\Alfa156\google-sync.json
```

Править этот файл вручную не нужно — используйте настройки внутри приложения.

## Решение проблем

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `Неизвестный токен` / `401 Unauthorized` | SYNC_TOKEN в приложении не совпадает с тем, что в Script properties | Проверьте и введите одинаковый токен в обоих местах |
| Ошибка проверки данных в ячейке (например, C9) | Старая версия скрипта на сервере | Переопубликуйте deployment: **New version** |
| Таблица пустая после sync | Вы сделали pull перед push | Сначала нажмите push, чтобы отправить локальные данные в таблицу |
| Не открывается URL веб-приложения | Доступ «Anyone» не выбран при деплое | Пересоздайте развертывание с `Who has access: Anyone` |

## ⚠️ Безопасность

- **НИКОГДА не публикуйте свой `SYNC_TOKEN` в интернете.** Он даёт доступ к вашей таблице Google.
- **НИКОГДА не выкладывайте файл `google-sync.json` в публичный репозиторий.**
- Каждый пользователь приложения должен создать **свою** таблицу, **свой** Apps Script и **свой** `SYNC_TOKEN`.
- Если вы распространяете приложение (например, через GitHub Releases), не вшивайте в него свою ссылку на таблицу и свой токен. Пользователь вводит их самостоятельно при первом запуске.
