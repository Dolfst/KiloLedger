# Синхронизация KiloLedger с Google Sheets

[English](../README.md#synchronization) · [Русский](../README.ru.md#синхронизация)

Инструкция для пользователей, которые впервые настраивают обмен данными между приложением **KiloLedger** (Desktop и Android) и своей таблицей в **Google Sheets** через Google Apps Script. КПК в Google напрямую не ходит.

## Что нужно перед началом

- Аккаунт Google (Gmail).
- Приложение **KiloLedger Desktop** (версия 1.37.0 и выше) или **KiloLedger Android**.
- Примерно 10–15 минут свободного времени.

> **Важно:** Синхронизация работает через вашу собственную таблицу Google Sheets. Приложение не имеет доступа к чужим таблицам, и вы не должны публиковать свои настройки в интернете.

---

## Шаг 1. Создайте Google Таблицу

1. Откройте [Google Sheets](https://sheets.google.com).
2. Нажмите **«Создать» → «Таблица»** (или откройте уже существующую таблицу).
3. Дайте таблице любое название, например `KiloLedger — Данные`.
4. Посмотрите на адресную строку браузера: часть ссылки между `/d/` и `/edit` — это **ID таблицы** (он может пригодиться на шаге 3, если вы будете создавать скрипт отдельно).

```text
https://docs.google.com/spreadsheets/d/ЗДЕСЬ_ИД_ТАБЛИЦЫ/edit
```

![ID таблицы в адресной строке Google Таблицы](screenshots/scr%20%282%29.png)

*На скриншоте выделена часть URL после `/d/` — сам ID таблицы заканчивается перед `/edit` (в примере выше это `1ks1B10NRzjc_IqdR-xFBp_TBBgkNoGUNeUahsqA6h3I`).*

---

## Шаг 2. Установите Apps Script

1. В своей таблице откройте меню **Расширения → Apps Script**.
2. Откроется редактор скриптов с пустой заготовкой `function myFunction() { }`. **Удалите весь этот код по умолчанию.**

![Пустой проект Apps Script с кодом по умолчанию](screenshots/scr%20%283%29.png)

3. Откройте файл [`KiloLedgerSync.gs`](KiloLedgerSync.gs) в репозитории (или скачайте [raw-файл](https://raw.githubusercontent.com/Dolfst/KiloLedger/main/google-sync/KiloLedgerSync.gs)), скопируйте **всё** его содержимое и вставьте в редактор `Код.gs`.
4. Нажмите значок сохранения (дискета) или `Ctrl + S` — надпись *«Несохранённые изменения»* должна исчезнуть.
5. При желании нажмите на заголовок **«Проект без названия»** вверху и переименуйте проект, например в `KiloLedger Синхр`.

![Редактор Apps Script со вставленным кодом KiloLedgerSync.gs](screenshots/scr%20%284%29.png)

---

## Шаг 3. Настройте свойства скрипта (`SYNC_TOKEN`)

1. В левой боковой панели редактора Apps Script нажмите значок шестерёнки **⚙ Настройки проекта** (*Project Settings*).
2. Прокрутите страницу вниз до раздела **«Свойства скрипта»** (*Script properties*) и нажмите **«Добавить свойство скрипта»** (*Add script property*).

![Раздел Свойства скрипта в настройках проекта Apps Script](screenshots/scr%20%285%29.png)

3. Введите свойство и значение:

   | Свойство | Значение |
   |----------|----------|
   | `SYNC_TOKEN` | Придумайте любой надёжный пароль (например, `kJ7#mP2vL9`) |

   > Это **не ваш пароль от Google**, а секретный код, который вы придумываете сами. Его же нужно будет указать в приложении KiloLedger для защиты соединения.

4. Нажмите синюю кнопку **«Сохранить свойства скрипта»**.

![Заполненное свойство SYNC_TOKEN](screenshots/scr%20%286%29.png)

5. *(Только если скрипт создан отдельно, а не через «Расширения → Apps Script» из таблицы)*: нажмите **«Добавить свойство скрипта»** ещё раз и добавьте второе свойство `SPREADSHEET_ID` с ID таблицы из шага 1, затем снова нажмите **«Сохранить свойства скрипта»**.

   | Свойство | Значение |
   |----------|----------|
   | `SPREADSHEET_ID` | ID вашей таблицы (строка между `/d/` и `/edit` из шага 1) |

![Добавление второго свойства SPREADSHEET_ID при необходимости](screenshots/scr%20%287%29.png)

## Шаг 4. Разверните как веб-приложение

1. В правом верхнем углу редактора нажмите синюю кнопку **«Начать развертывание»** → **«Новое развертывание»** (*Deploy → New deployment*).

![Меню Начать развертывание — Новое развертывание](screenshots/scr%20%288%29.png)

2. В открывшемся окне нажмите на значок шестерёнки рядом с **«Выберите тип»** и выберите **«Веб-приложение»** (*Web app*).

![Выбор типа развертывания Веб-приложение](screenshots/scr%20%289%29.png)

3. Настройте параметры:

   | Параметр | Значение |
   |----------|----------|
   | Запуск от имени (*Execute as*) | **От моего имени** (*Me*) |
   | У кого есть доступ (*Who has access*) | **Все** (*Anyone*) |

   > Доступ **«Все»** нужен, чтобы приложение KiloLedger могло обращаться к скрипту по URL без интерактивного входа в Google. Запись и чтение всё равно защищены вашим секретным `SYNC_TOKEN`.

4. Нажмите синюю кнопку **«Начать развертывание»**.

![Параметры веб-приложения и кнопка Начать развертывание](screenshots/scr%20%2810%29.png)

### Авторизация доступа при первом развертывании

При первом запуске Google попросит подтвердить, что вы разрешаете собственному скрипту работать с вашими таблицами. Так как скрипт не проходил публичную публикацию в каталоге Google, появится экран предупреждения — это нормально:

5. На экране **«Google не проверил это приложение»** нажмите ссылку **«Дополнительно»** слева внизу *(не нажимайте «Вернуться к разделу безопасности»)*.

![Окно предупреждения Google не проверил это приложение — нажмите Дополнительно](screenshots/scr%20%2811%29.png)

6. В раскрывшемся описании нажмите ссылку **«Перейти к проекту … (небезопасно)»** в самом низу.

![Нажмите Перейти к проекту (небезопасно)](screenshots/scr%20%2812%29.png)

7. На экране запроса разрешений для работы с таблицами Google Sheets нажмите **«Продолжить»** справа внизу.

![Подтверждение доступа к Google Sheets — кнопка Продолжить](screenshots/scr%20%2813%29.png)

### Получение URL веб-приложения

8. После завершения откроется окно **«Новое развертывание»**. В блоке **«Веб-приложение»** скопируйте **URL** (кнопка **«ОК»** / копировать) и нажмите **«Готово»**.

   ```text
   https://script.google.com/macros/s/AKfycb.../exec
   ```

   > **Важно:** в приложение нужно вставлять именно **URL веб-приложения** (`https://script.google.com/macros/s/.../exec`), а **не** «Идентификатор развертывания» и не обычную ссылку на саму Google Таблицу.

![Окно завершения развертывания и URL веб-приложения](screenshots/scr%20%281%29.png)

## Шаг 5. Настройте KiloLedger Desktop

### Вариант А: через мастер (рекомендуется)

1. Запустите **KiloLedger Desktop**.
2. Откройте меню **«Обмен ▾» → «Google: мастер»** (или **«Обмен ▾» → «Центр Google Sync» → «Google: мастер»**, либо на вкладке **«Настройки»** в карточке **«Центр Google Sync»**).
3. Мастер проведёт вас через три шага:
   - **Шаг 1.** Краткая инструкция и ссылка на этот README.
   - **Шаг 2.** Вставьте **URL веб-приложения** (из шага 4) и **SYNC_TOKEN** (который вы задали на шаге 3). При желании можно также указать ссылку на саму таблицу Google Sheets.
   - **Шаг 3.** Нажмите **«Проверить подключение»** (выполнит тестовый `pull`) и затем **«Готово»**.

### Вариант Б: ручная настройка

1. Откройте **«Обмен ▾» → «Google: настройка»** (или через **«Настройки» → «Google: настройка»**).
2. В поле **URL веб-приложения Apps Script** вставьте скопированный URL из шага 4.
3. В поле **SYNC_TOKEN** введите придуманный пароль из шага 3.
4. Нажмите **ОК / Сохранить**.

---

## Шаг 6. Первая синхронизация

1. Нажмите **«Обмен ▾» → «Синхронизация Google»** (или кнопку в **«Центре Google Sync»**).
2. Сначала пройдёт **pull** — загрузка данных из вашей таблицы Google. Если таблица новая и пустая, локальные данные не изменятся.
3. Откроется окно предпросмотра слияния: проверьте параметры и подтвердите синхронизацию — локальные записи из `.dat` файлов отправятся в таблицу (**push**).
4. Скрипт автоматически создаст нужные листы: `Заправки {авто}`, `Ремонт {авто}`, `Прочие {авто}`, `Коммунальные`, `Справочник`, `Кат. прочих`.

## Для пользователей Android

1. Откройте **KiloLedger Android**.
2. Перейдите в **Данные → Google: настройка**.
3. Вставьте те же **URL веб-приложения** и **SYNC_TOKEN**, что и на Desktop.
4. Нажмите **Сохранить**.
5. Используйте **Данные → Синхронизация Google** в приложении.

## Обновление Apps Script после правок

Если вы обновляете код `KiloLedgerSync.gs` (например, после выхода новой версии приложения), **обязательно опубликуйте новую версию развертывания**, иначе на сервере Google останется старый код:

1. В редакторе Apps Script нажмите **«Начать развертывание» → «Управление развертываниями»** *(пункт виден в том же выпадающем меню на скриншоте к шагу 4)*.
2. Выберите ваше активное развертывание и нажмите значок карандаша (**Изменить** / *Edit*).
3. В списке **«Версия»** выберите **«Новая версия»** (*New version*).
4. Нажмите **«Начать развертывание»** (*Deploy*).

Без этого шага новые колонки или исправления в скрипте не начнут работать.

## Конфликты и особенности

| Ситуация | Что происходит |
|----------|----------------|
| Запись есть только в Google | При синхронизации она добавится локально |
| Запись есть только локально | Она отправится в Google при push |
| Одна и та же запись изменилась с обеих сторон | Приложение покажет выбор, какую версию оставить |
| Локальные «лишние» записи | По умолчанию не удаляются |

### Важное ограничение про `id` и удаления

Локальные `.dat` файлы хранят стабильные идентификаторы записей и метки удаления (`deleted.dat`). В Google Sheets идентификаторы не записываются (структура колонок не меняется), поэтому обмен с таблицей идёт по естественным ключам (дата + автомобиль + пробег / сумма и т.п.). Надёжная передача удалений работает через **Wi‑Fi (Android ↔ КПК)** и **ZIP / папку `.dat`**, а не через Google.

## Где хранятся настройки

На Windows Desktop конфигурация синхронизации сохраняется здесь:

```text
%AppData%\KiloLedger\google-sync.json
```

Править этот файл вручную не нужно — используйте **«Google: мастер»** или **«Google: настройка»** внутри приложения.

## Решение проблем

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `Неверный token` / `401 Unauthorized` | `SYNC_TOKEN` в приложении не совпадает с тем, что указан в Script properties | Проверьте и введите одинаковый токен в обоих местах |
| Ошибка проверки данных в ячейке (например, `C9`) | На сервере осталась старая версия скрипта | Переопубликуйте развертывание: **Управление развертываниями → Изменить → Новая версия** |
| Таблица пустая после sync | Настройки не сохранены или отменён диалог слияния | Проверьте URL веб-приложения и подтвердите применение в диалоге синхронизации |
| Не открывается / возвращает HTML вместо JSON | При деплое не выбран доступ «Все» (*Anyone*) или URL скопирован не из раздела «Веб-приложение» | Пересоздайте развертывание с доступом **«Все»** и скопируйте ссылку вида `https://script.google.com/macros/s/.../exec` |

## Безопасность

- **НИКОГДА не публикуйте свой `SYNC_TOKEN` и URL веб-приложения в интернете.** Вместе они дают доступ к изменению вашей таблицы Google.
- **НИКОГДА не выкладывайте файл `google-sync.json` в публичный репозиторий.**
- Каждый пользователь приложения должен создать **свою** таблицу, **свой** Apps Script и **свой** `SYNC_TOKEN`.
- Если вы распространяете или собираете приложение для других пользователей, не вшивайте в него свою ссылку и токен — каждый пользователь вводит их самостоятельно.
